Add television clips here.

Files in this directory and its subdirectories form one shared randomized
broadcast. Every loaded MMVP television displays the same clip and timeline.
The Pip-Boy holotape's TV option randomly selects a file from this folder.

Move the mouse to show Previous, Play/Pause, Next, Stop, and seek controls.
Clicks on those controls are kept inside the video player instead of passing
through to the underlying Pip-Boy menu.
